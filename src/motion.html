One principle, six rules.

Motion tells him something happened: a button heard him, a panel opened, a step moved on. It never decorates, never asks for attention, never repeats.

Motion confirms, it never performs.

Every unifiedmeds motion is a confirmation of something he did, or the single entrance of a brand shape. If a motion has neither job, it is cut.

  1. One easing for UI.

    Every UI transition uses ease-out (--motion-easing-ui). The enter curve (--motion-easing-enter) is only for brand shapes entering. Every duration and distance is a token.

  2. Brand shapes move only on entrance or with the scroll.

    A kit piece pivots or wipes once, when it enters. At most one shape entrance per view; the hero is static copy plus one shape entrance (R-53). A fold shape may drift with the scroll (R-111), and a landing page may carry three brand moments (R-104).

  3. Nothing loops except the loader.

    No drift on a timer, no carousels that advance by themselves, no pulsing. The capsule loader (1.4s) is the only loop, and only while he waits (R-53).

  4. Reduced motion means instant and static.

    When he asks for reduced motion, every state change happens at once and nothing moves. Not shorter motion: no motion.

  5. No bounce, no overshoot.

    No spring, shake, stretch, scale or zoom. Things arrive and stop. The button lift is 2px and that is the largest UI movement there is, apart from the 12px rise.

  6. Disclaimers are visible at rest.

    Disclaimers, safety information, eligibility lines and prices are never animated into view. They are present on load, or they are not compliant.

Authority (R-01): decided rules and tokens win. The designer's Figma is the source only for what is not decided yet; its one motion value is the button note "Smart Animate, 150ms ease-out", which --motion-duration-fast matches. Our own Figma files are kept in sync with the rules. brand-rules.md R-49 to R-54, R-101, R-104, R-111 and R-113 are the rules this page explains.

Demo controls Your system asks for reduced motion, so every demo runs instantly and still. Turn the setting off to watch the motion.

Every value is a token.

Seven durations, three curves, four distances, a turn, two staggers and five timings, generated from the token file. They live in tokens/tokens.json and reach code as --motion-* custom properties in brand.css. Nothing else is allowed in a transition.

All seven bars start together; each fills in its own duration with ease-out.

Easing.

--motion-easing-ui · cubic-bezier(0, 0, 0.58, 1), the CSS ease-out. Every UI transition: hover, press, open, close, select, reveal, Rise, Count.

--motion-easing-enter · cubic-bezier(0.22, 1, 0.36, 1). Only brand shapes entering: Pivot and Wipe.

Both dots travel in --motion-duration-shape (520ms). The dashed line is --motion-easing-linear (cubic-bezier(0, 0, 1, 1)): it was the old loader's turn and now only maps a scroll position to a drift, which follows the scroll 1:1 (R-111). The capsule loader uses ease-out.

Write transitions with the tokens only, and list the properties that change (never all):

.btn {
  transition:
    background-color var(--motion-duration-fast) var(--motion-easing-ui),
    color            var(--motion-duration-fast) var(--motion-easing-ui),
    transform        var(--motion-duration-fast) var(--motion-easing-ui);
}
.btn:hover, .btn:focus-visible {
  transform: translateY(calc(var(--motion-distance-lift) * -1));
}

Mapped from the archived Main menu v3 spec (4010-609): item hover 180ms ease → --motion-duration-fast ease-out; dropdown open 180ms ease → --motion-duration-open ease-out; close fade 140ms → --motion-duration-fast.

Four brand moves.

Rise, Pivot, Wipe and Count are the only motions with a brand character. Each plays once. Shapes pivot or wipe; type rises; a result counts.

Motion confirms,it neverperforms.

Rise.

Type and content blocks rise 12px (--motion-distance-rise) and fade in, --motion-duration-reveal (320ms), --motion-easing-ui, 90ms apart, three at most. Never hero copy. M-021

Pivot.

A kit piece turns exactly 90° about its anchored corner into place. --motion-duration-shape (520ms), --motion-easing-enter. No fade, no scale. M-019

Wipe.

A straight edge uncovers a kit piece from left to right. --motion-duration-wipe (420ms), --motion-easing-enter. No opacity change. M-020

18.2Sample value, not real data

Count.

A member’s own result is uncovered from right to left, as if written. Results only. --motion-duration-wipe, --motion-easing-ui To confirm. Never a rolling odometer. M-022

Reduced motion means no motion.

When the operating system asks for reduced motion, unifiedmeds does not shorten its motion. It removes it. Every state still changes; nothing travels.

What still happens

Colours, borders, selection, open and close: all change instantly. The intent delay (100ms), close delay (150ms), loader delay (400ms) and the assessment’s 320ms auto-advance pause stay, because they protect his intent and are not motion. Every block is visible at load. The loader shows a still capsule, half filled, with its sentence.

What stops

Every movement: lift, rise, drop, Pivot, Wipe, Count, stagger, slides. Smooth scrolling (scroll-behavior: auto). The loader’s fill cycle. Fold drift and turn, landing-page moments. Any animation started by script.

brand.css does most of the work. Inside @media (prefers-reduced-motion: reduce) it sets every --motion-duration-* (except the loader) to 0ms, every --motion-distance-* to 0px, both staggers to 0ms and the drift turn to 0deg, so any component built on the tokens becomes instant and still on its own. Two things need code of their own:

  • The loader. Set animation: none on the fill and show it at half (transform: scaleX(0.5)), with the sentence.
  • Script. Check the preference before smooth scrolling, before adding a Reveal’s hidden state, and before starting any animation. Listen for changes.
const reduce = window.matchMedia('(prefers-reduced-motion: reduce)');
target.scrollIntoView({ behavior: reduce.matches ? 'auto' : 'smooth' });
if (!reduce.matches) observeReveals();   // never hide content when motion is off

Never fake it with 0.01ms durations or iteration tricks, never ignore the setting in demos, and never let reduced motion hide content or change the order of anything.

Test it. macOS: System Settings › Accessibility › Display › Reduce motion. iOS: Settings › Accessibility › Motion › Reduce Motion. Windows 11: Settings › Accessibility › Visual effects › Animation effects (off). Chrome DevTools: Rendering › Emulate CSS media feature prefers-reduced-motion. The demos on this page follow your setting, and the “Preview reduced motion” control shows the result without changing it.

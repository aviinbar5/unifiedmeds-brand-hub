How this hub works.

Three things to know before you use anything here.

Decided rules and tokens win.

Every rule is in the rulebook, every value in tokens.json. When a page, a file or a Figma frame disagrees, the rule wins (R-01).

Figma follows the rules.

Our own Figma files are kept in sync with the rules and tokens. The designer's files are read only and are the source only for what is not decided yet.

Marked when not final.

A yellow dot in the menu, or a "Proposed" label on a page, means waiting for approval. Placeholder photos read "Not approved · to replace".

Buttons.

Five types, one height, one shape, one motion. Source: Figma Buttons — Hover Rules 2676-309 (board 2719-4438) and Avi’s button rule of 08.10.2026 (R-40).

Rounded rectangle, fixed padding.

Buttons are rounded rectangles with 5px corners (--radius-button), never pills: the capsule belongs to the logo (decision U-11, Avi 15.11.2026). Height 50px (--size-control), side padding 24px (--size-button-padding-x), so width = label width + 48. The dashed lines mark the padding; the dashed box is the label. Source: Figma Button set 2676-310.

Motion.

150ms ease-out.

Colour, border and lift share one transition: --motion-duration-fast with --motion-easing-ui. Press = hover = 150ms.

Lift 2px.

Every button rises --motion-distance-lift on hover and settles back on press. No shadow, no scale.

Reduced motion.

With prefers-reduced-motion the colour changes instantly and nothing lifts (brand.css sets both tokens to 0).

Labels and use.

Do.

Sentence case: “Get started”, “Explore treatments”, “Start your assessment”, “Learn more”. One primary action per view. One Yellow element per viewport. Full width only for E-03 and the footer CTA on mobile.

Don’t.

Title case (“Get Started”), a second size, a shadow, a Pastel Blue fill, Yellow text, a label that wraps, or a Back button in its own style (use Outline).
